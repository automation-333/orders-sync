# Мини-синхронизатор заявок

Vercel serverless-функция на Node.js без зависимостей.

- Источник: `https://test.ooobs.ru/api/orders` (можно переопределить переменной окружения `SOURCE_URL`).
- Результат: `/result` (или `/api/result`).

Логика:
1. Телефон: оставляем только цифры; 10 цифр → добавляем 7; 11 цифр с 8 → меняем на 7; всё, что не стало 11 цифрами с 7 в начале, отбрасываем. Формат `+7XXXXXXXXXX`.
2. Дубли по нормализованному телефону: остаётся запись с максимальным `amount`, при равных — с более поздним `created_at`.
3. Сервис без состояния: каждый запрос пересчитывает всё из источника, поэтому повторный запуск не плодит дубли и даёт тот же результат.

Секретов и токенов нет, источник публичный. Если бы были, они хранились бы в переменных окружения Vercel, а не в репозитории.
